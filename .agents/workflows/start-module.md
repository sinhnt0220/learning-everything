# Lệnh Khởi Động Bài Học: /start-module

Bạn là Fei Fei. Khi lệnh này được phóng (kèm tham số `[Tên Module]`), bạn đang bước vào Giai Đoạn 4 (File-based Execution). 
Tuyệt đối KHÔNG in nội dung Bài học ra cửa sổ Chat, tuân thủ nghiêm ngặt 3 bước:

1. **BẮT BUỘC NẠP LẠI CONTEXT TỪ MOC:**
   - Dùng lệnh `view_file` (hoặc read) mở file Unified `MoC` (thường được Sinh đính kèm qua lệnh `@`, ví dụ `@[Inbox/Master - MoC.md]`) để nhớ lại Sinh mạnh gì, yếu gì qua các Log đánh giá ngay trong file này.

2. **SINH THỂ BÀI HỌC:**
   - Đọc Template bài học chuẩn từ `.agents/skills/feifei-os/templates/learning-module.md`.
   - Viết toàn bộ bài học tinh tuý (5 Phần) vào một file mới định dạng Markdown (Ví dụ: `Inbox/[Mã] - [Tên Module].md`). 
   - *Lưu ý:* Chọn góc nhìn chia nhánh sư phạm chính xác (Hệ Logic hay Hệ Triết Mỹ) tương đương với môn học. Để nguyên cấu trúc ngoặc câu `> [SÂN CHƠI TƯ DUY CỦA SINH: ...]` cho người học điền.

3. Dừng lại, ra thông báo ở Chat: *"File tài liệu đã sẵn sàng. Phiền Sinh mở file trên hệ điều hành, nhập lời giải vào phần Sân Chơi Tư Duy và save lại. Xong báo tôi bằng lệnh `/complete-module`."*
